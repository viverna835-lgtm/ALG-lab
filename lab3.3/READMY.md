## 3. Код программы:

Поскольку класс является шаблонным, его реализация находится полностью в заголовочном файле `.h` (это стандартное требование C++ для шаблонов).

### Файл Vector.h (Объявление класса)

Приватные поля и вспомогательный метод `detach()` для ленивого копирования

```cpp
#pragma once
#include <iostream>
#include <stdexcept>
#include <utility> 

using namespace std;

template <typename T>
class Vector {
private:
    T* data;       // Указатель на массив
    int sz;        // Текущий размер (количество элементов)
    int cap;       // Выделенная емкость
    
    // Для ленивого копирования (Copy-on-Write)
    int* refCount; // Счетчик ссылок на массив

    // Вспомогательный метод для отвязки от общей памяти (при записи)
    void detach() {
        if (refCount && *refCount > 1) {
            // Если нас больше одного, создаем свою копию
            T* newData = new T[cap];
            for (int i = 0; i < sz; ++i) newData[i] = data[i];
            
            (*refCount)--; // Уменьшаем старый счетчик
            
            data = newData;
            refCount = new int(1); // Новый счетчик для себя
        }
    }
```
Конструкторы и деструктор (Правило пяти)

```cpp
public:
    // --- Конструкторы ---
    Vector() : data(nullptr), sz(0), cap(0), refCount(nullptr) {}

    explicit Vector(int n) : sz(n), cap(n), refCount(new int(1)) {
        if (n < 0) throw invalid_argument("Размер не может быть отрицательным");
        data = new T[cap];
        for (int i = 0; i < sz; ++i) data[i] = T();
    }

    // Конструктор копирования (ЛЕНИВОЕ КОПИРОВАНИЕ!)
    Vector(const Vector& other) : data(other.data), sz(other.sz), cap(other.cap), refCount(other.refCount) {
        if (refCount) (*refCount)++; // Просто увеличиваем счетчик, не копируем данные!
    }

    // Конструктор перемещения
    Vector(Vector&& other) noexcept 
        : data(other.data), sz(other.sz), cap(other.cap), refCount(other.refCount) {
        other.data = nullptr;
        other.sz = 0;
        other.cap = 0;
        other.refCount = nullptr;
    }

    // --- Деструктор ---
    ~Vector() {
        if (refCount) {
            (*refCount)--;
            if (*refCount == 0) {
                delete[] data;
                delete refCount;
            }
        }
    }
```
Операторы присваивания

```cpp
    // --- Оператор присваивания копированием ---
    Vector& operator=(const Vector& other) {
        if (this != &other) {
            if (refCount) {
                (*refCount)--;
                if (*refCount == 0) {
                    delete[] data;
                    delete refCount;
                }
            }
            data = other.data;
            sz = other.sz;
            cap = other.cap;
            refCount = other.refCount;
            if (refCount) (*refCount)++;
        }
        return *this;
    }

    // --- Оператор присваивания перемещением ---
    Vector& operator=(Vector&& other) noexcept {
        if (this != &other) {
            if (refCount) {
                (*refCount)--;
                if (*refCount == 0) {
                    delete[] data;
                    delete refCount;
                }
            }
            data = other.data;
            sz = other.sz;
            cap = other.cap;
            refCount = other.refCount;
            
            other.data = nullptr;
            other.sz = 0;
            other.cap = 0;
            other.refCount = nullptr;
        }
        return *this;
    }
```
Методы доступа, оператор [] и изменение размера

```cpp
    // --- Методы доступа ---
    int size() const { return sz; }
    int capacity() const { return cap; }
    bool empty() const { return sz == 0; }

    // --- Оператор [] с проверкой и Detach ---
    T& operator[](int index) {
        if (index < 0 || index >= sz) throw out_of_range("Индекс вне диапазона");
        detach(); // <-- ВАЖНО! Если массив общий, делаем копию перед изменением
        return data[index];
    }

    const T& operator[](int index) const {
        if (index < 0 || index >= sz) throw out_of_range("Индекс вне диапазона");
        return data[index];
    }

    // --- Изменение размера ---
    void push_back(const T& value) {
        detach(); // Отвязываемся, если нужно менять
        if (sz >= cap) {
            int newCap = (cap == 0) ? 1 : cap * 2;
            T* newData = new T[newCap];
            for (int i = 0; i < sz; ++i) newData[i] = data[i];
            delete[] data;
            data = newData;
            cap = newCap;
        }
        data[sz++] = value;
    }

    void pop_back() {
        detach();
        if (empty()) throw underflow_error("Вектор пуст");
        sz--;
    }
```
Итераторы и очистка

```cpp

    T* end() { detach(); return data + sz; }
    const T* begin() const { return data; }
    const T* end() const { return data + sz; }

    // --- Очистка ---
    void clear() {
        detach();
        sz = 0;
    }
};
```

## 5. Анализ сложности операций
Операция	Сложность	Обоснование
push_back	O(1) амортизированная	В среднем добавление в конец вектора занимает константное время. При переполнении емкость удваивается, и происходит копирование всех элементов (O(n)), но это происходит редко, поэтому в среднем O(1). pop_back	O(1)	Удаление последнего элемента не требует сдвига остальных.
operator[]	O(1)	Доступ по индексу — это вычисление адреса элемента за константное время.
Конструктор копирования (Copy-on-Write)	O(1)	При копировании мы не копируем данные, а только увеличиваем счетчик ссылок (в текущей реализации — это константное время).
Изменение элемента (с Copy-on-Write)	O(n)	Если объект не единственный владелец памяти, detach() создает полную копию массива (O(n)).
## 6. Ответы на контрольные вопросы
1. Почему динамический массив называется «динамическим»?
Потому что его размер может изменяться во время выполнения программы (в отличие от статического массива, размер которого фиксирован на этапе компиляции).

2. Что такое ёмкость (capacity) и чем она отличается от размера (size)?
size — это количество элементов, которые реально хранятся в массиве. capacity — это количество элементов, под которые выделена память. capacity всегда больше или равно size.

3. Почему при расширении массива ёмкость удваивается, а не увеличивается на фиксированное число?
Удвоение обеспечивает амортизированную сложность O(1) для push_back. Если увеличивать на 1, то каждая вставка будет требовать копирования всего массива, что даст сложность O(n 2) для n вставок.

4. Какова амортизированная сложность операции push_back? Почему?
Амортизированная сложность — 
O(1). Потому что, хотя иногда происходит «дорогое» расширение с копированием n элементов, эти затраты «размазываются» по всем предыдущим операциям добавления.

5. Что такое «правило трёх»? Когда оно применяется?
Если классу нужен деструктор, конструктор копирования или оператор присваивания (из-за управления ресурсами), то нужно реализовать все три. Применяется для классов, владеющих динамической памятью.

6. Что такое «правило пяти»? Чем оно отличается от «правила трёх»?
К трем методам добавляются конструктор перемещения и оператор присваивания перемещением (для эффективной передачи ресурсов из временных объектов). Появилось в C++11.

7. В чём разница между конструктором копирования и оператором присваивания?
Конструктор копирования создает новый объект на основе существующего. Оператор присваивания заменяет содержимое уже существующего объекта.

8. Зачем нужна проверка if (this != &other) в операторе присваивания?
Чтобы избежать самоприсваивания (v = v). Без проверки мы бы сначала удалили память объекта, а потом попытались бы скопировать данные из уже удаленной памяти, что привело бы к ошибке.

9. Что такое итератор? Как он связан с указателем?
Итератор — это объект, позволяющий перебирать элементы контейнера. В нашем классе итератор — это обычный указатель (T*). В более сложных контейнерах это может быть отдельный класс.

10. Зачем нужны методы begin() и end()?
begin() возвращает итератор на первый элемент, end() — на элемент, следующий за последним. Это нужно для работы циклов for (auto x : v) и алгоритмов STL.

11. Как реализовать range-based for для своего контейнера?
Нужно реализовать методы begin() и end(), возвращающие итераторы (или указатели). Цикл автоматически будет вызывать эти методы.

12. Что такое «глубокое копирование»? Чем оно отличается от «поверхностного»?
Глубокое копирование создает полностью независимую копию данных (новый массив). Поверхностное копирует только указатели, из-за чего два объекта указывают на одну и ту же память.

13. Что такое семантика перемещения и зачем она нужна?
Это механизм, позволяющий «забрать» ресурсы у временного объекта, а не копировать их. Это значительно ускоряет работу программы (например, возврат вектора из функции).

14. Почему конструктор перемещения помечается noexcept?
Чтобы стандартная библиотека (например, std::vector) знала, что при перемещении исключений не будет, и использовала перемещение вместо копирования для оптимизации.

15. Как правильно освобождать память в деструкторе?
Для массивов, выделенных через new[], используется delete[] data;. Также в нашем случае нужно не забыть удалить счетчик ссылок delete refCount;, если он больше не нужен.
